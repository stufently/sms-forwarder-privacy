Privacy Policy — SMS Forwarder

English below the line is followed by a Russian version («Политика конфиденциальности» ниже).

Effective date: 2026-11-10 · App: SMS Forwarder (com.stufently.smsforwarder) · Developer contact: [EMAIL — fill in before publishing]

1. Summary

SMS Forwarder forwards SMS messages that arrive on your phone to destinations you configure (Telegram, e-mail, a webhook URL, or another phone number by SMS), according to rules you write. Everything happens on your device. The developer runs no servers, receives none of your messages and collects no analytics. The app contains no ads and no third-party tracking SDKs.

2. Data the app accesses

DataWhyWhere it goes
Incoming SMS: text, sender number, time, SIM slot / subscriptionCheck your rules and forward matching messagesStored encrypted on the device; matching messages are sent only to the destinations you configured

The app requests these permissions:

  • Receive SMS (RECEIVE_SMS) — core function: read incoming messages to forward them.
  • Send SMS (SEND_SMS) — only if you create an "another number" destination; requested on that screen, not at first launch.
  • Notifications, foreground service (remote messaging), run at startup, internet / network state — to deliver messages in the background reliably and show that forwarding is working.

The app does not read your existing SMS inbox, contacts, call log, location or files.

3. Sharing

Messages are shared only with the destinations you set up, and only when one of your rules matches:

  • Telegram (Telegram Bot API, via the bot token you provide);
  • E-mail through the SMTP server you specify (unencrypted SMTP is allowed only to a server in your local network);
  • Webhook — an HTTPS address you specify (plain HTTP is blocked);
  • Another phone number — an SMS sent from your phone through your carrier.

These recipients are third parties chosen by you. Their handling of the data is governed by their own terms and privacy policies. The developer never receives the data. If you configure a health-check URL, the app sends a periodic request to it that contains no message content.

4. Storage, security and retention

  • Message text and secrets are encrypted on the device (AES-256-GCM, key in Android Keystore).
  • You choose how long message text is kept: 1 day, 7 days, 30 days or without limit. After that period the text is erased; delivery metadata (time, status) stays in the log.
  • The app's database and settings are excluded from Android cloud backup and device transfer.
  • A rules export file you create yourself may contain destination settings (for example a webhook URL); secrets are included only if you choose a password-protected backup. Keep such files private.

5. Your choices and deletion

  • Pause forwarding at any time on the main screen.
  • Revoke SMS permissions in Android settings at any time.
  • Delete all data: Android settings → Apps → SMS Forwarder → Storage → Clear storage, or uninstall the app. Because the developer holds no copy, nothing remains with the developer.

6. Children

The app is not directed at children under 13 and is not designed for them.

7. Prohibited use

The app must not be used to monitor another person's messages. Install it only on a phone you own and use. Nobody should ask you to install it in order to receive your codes.

8. Changes

Material changes will be published at this address with a new effective date, and the app will ask for consent again if the way SMS data is used changes.

Политика конфиденциальности — SMS Forwarder

Действует с 2026-11-10 · Приложение: SMS Forwarder (com.stufently.smsforwarder) · Связь с разработчиком: [EMAIL — заполнить перед публикацией]

1. Коротко

SMS Forwarder пересылает SMS, пришедшие на ваш телефон, в назначения, которые настраиваете вы (Telegram, электронная почта, адрес вебхука или другой номер по SMS), по правилам, которые задаёте вы. Всё происходит на устройстве. У разработчика нет серверов, он не получает ваших сообщений и не собирает аналитику. В приложении нет рекламы и сторонних SDK отслеживания.

2. К каким данным приложение обращается

Разрешения:

  • Приём SMS (RECEIVE_SMS) — основная функция: читать входящие, чтобы пересылать.
  • Отправка SMS (SEND_SMS) — только если вы создаёте назначение «на другой номер»; спрашивается на этом экране, а не при первом запуске.
  • Уведомления, foreground service (remote messaging), запуск после загрузки, интернет / состояние сети — чтобы надёжно доставлять в фоне и показывать, что пересылка работает.

Приложение не читает уже сохранённые SMS, контакты, журнал звонков, местоположение и файлы.

3. Передача данных

Сообщения передаются только в настроенные вами назначения и только когда срабатывает одно из ваших правил:

  • Telegram (Telegram Bot API, через указанный вами токен бота);
  • Почта через указанный вами SMTP-сервер (без шифрования — только сервер в локальной сети);
  • Вебхук — указанный вами адрес HTTPS (обычный HTTP заблокирован);
  • Другой номер — SMS с вашего телефона через вашего оператора.

Эти получатели — третьи стороны, выбранные вами; обработку данных у них регулируют их условия и политики конфиденциальности. Разработчик данных не получает. Если вы указали адрес мониторинга (health-check), приложение периодически обращается к нему без содержимого сообщений.

4. Хранение, защита и сроки

  • Текст сообщений и секреты зашифрованы на устройстве (AES-256-GCM, ключ в Android Keystore).
  • Срок хранения текста выбираете вы: сутки, 7 дней, 30 дней или бессрочно. После него текст стирается; метаданные доставки (время, статус) остаются в журнале.
  • База и настройки приложения исключены из облачного резервного копирования Android и переноса на новое устройство.
  • Файл экспорта правил, который вы создаёте сами, может содержать параметры назначений (например, адрес вебхука); секреты попадают в него только при резервной копии с паролем. Храните такие файлы в тайне.

5. Ваш выбор и удаление

  • Пересылку можно приостановить на главном экране в любой момент.
  • Разрешения на SMS можно отозвать в настройках Android в любой момент.
  • Удалить все данные: Настройки Android → Приложения → SMS Forwarder → Хранилище → Очистить, или удалить приложение. Копии у разработчика нет, поэтому у него ничего не остаётся.

6. Дети

Приложение не предназначено для детей младше 13 лет.

7. Запрещённое использование

Приложение нельзя использовать для слежки за чужими сообщениями. Устанавливайте его только на свой телефон. Никто не должен просить вас установить его, чтобы получать ваши коды.

8. Изменения

Существенные изменения публикуются по этому адресу с новой датой; если меняется способ использования SMS, приложение заново спросит согласие.
